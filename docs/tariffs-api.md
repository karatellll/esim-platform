# Экран «Страна · тарифы»

Реализовано 15 октября 2026 года. Дизайн:
[Figma, 64:3926](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=64-3926).
Прочитаны высокодетальный контекст и изображение экрана.

## Сценарий

Нажатие на любую страну в каталоге открывает общий экран тарифов с её SDK ID.
Экран находится в native stack поверх вкладок: таб-бар на нём скрыт, кнопка
«Назад» возвращает в каталог. Идентификатор, название и флаг берутся из API.
Для заголовка название склоняется в предложный падеж; длинные названия
адаптируются по ширине, а строка заголовка может переноситься.

```text
Страны → выбор страны
       → GET /api/catalog/esims/{id}/tariffs (наш FastAPI)
       → GET /v1/sdk/esims/{id}/tariffs (поставщик)
```

Запрос поставщику идёт с серверными ClientToken и X-Publishable-Key.
Выпуск, переиспользование и однократное обновление токена при 401 общие
с каталогом. Клиент не получает ключи или токен. Параметр маршрута — UUID;
ответ с ID другой страны отклоняется. Ненайденное направление возвращает 404.

## Проверенный контракт

SDK возвращает `data: {esim, tariffs}`. Данные страны преобразуются в тот же
`CatalogEsim`, что и в каталоге. Тариф содержит:

- `id`, `display_name`;
- `price_amount_minor`, `price_currency`;
- `data_amount: {amount, unit}`;
- `duration: {amount, unit}`;
- `is_profitable_badge`.

Наш API дополнительно возвращает `is_unlimited`: для проверенных ответов
это сочетание нулевого объёма и слова «Безлимит»/`unlimited` в названии.
Один нулевой объём без явного названия не обещает безлимит.
Неизвестные поля поставщика удаляются.

Цена отображается в той же шкале, что принята для SDK-каталога: число передаётся
без пересчёта, `439 RUB` → «439 ₽». Имя `price_amount_minor` сохраняется в контракте;
деление на 100 не применяется. Полная спецификация поставщика пока недоступна.

Схемы: `packages/shared/contracts/tariffs.schema.json`, `openapi.json`, `catalog.ts`.

## Глобальный пакет

Текущий переход с зелёной карточки реализован во вкладку «Весь мир»
по Figma `103:49480`, с сохранением таб-бара и списком тарифов XG.
[Поведение, данные и проверки](world-screen.md).
Общий экран страны по-прежнему поддерживает XG при прямом внутреннем
переходе, но зелёная карточка больше не открывает его.

## Поведение интерфейса

- Доступные сроки выводятся из ответа, без добавления несуществующих тарифов.
  По умолчанию выбран срок 15 дней, если он есть, иначе самый короткий.
- При смене срока остаются только соответствующие пакеты. Карточки отсортированы
  по объёму; безлимит расположен после ограниченных пакетов.
- Первоначально выбирается тариф с `is_profitable_badge`, затем 5 ГБ при наличии,
  иначе первый доступный пакет. Нажатие карточки меняет выбор и нижний итог.
- Синяя обводка и оригинальный декоративный значок глаз отмечают выбранную
  карточку. «Выгодно» выводится только по флагу API. Проценты скидок не выдумываются.
- Строка под карточками показывает фактический выбранный объём и срок.
  ИИ-прогноз расхода, сети и 5G из примера не показываются: этих полей нет
  в проверенном ответе. Вместо строки операторов — предложение выбрать срок и объём.
- Учтены загрузка, ошибка с повтором, отсутствие тарифов и отмена запроса при уходе.
- «Поделиться» открывает системную отправку на телефоне; в web — окно с текстом
  выбранного предложения, который можно выделить и скопировать.
- «Купить» открывает сведения о выбранном тарифе с сообщением «Покупка будет
  доступна позже». Заказ, списание денег и вызов платёжного API не реализованы.

## Ресурсы и размеры

Оригинальные SVG скачаны из контекста Figma в `apps/mobile/assets/tariffs`:

| Файл | Слой | Исходный размер | Использование |
|---|---|---|---|
| `back.svg` | `64:3930` | 20 × 20 | кнопка навигации 40 × 40 |
| `share.svg` | `64:3932` | 20 × 20 | кнопка отправки 40 × 40 |
| `sticker.svg` | `64:3941` | 123 × 41 | стикер названия, поворот 1,5° |
| `eyes-card.svg` | `64:3961` | 28,8 × 18 | выбранная карточка |
| `eyes-hint.svg` | `64:3971` | 25,6 × 16 | строка выбора |

Флаг динамический из API. Для Турции стикер имеет исходные размеры; длинные
названия расширяют его через transform без изменения файла SVG.
Карточки высотой 100, радиусом 20, промежутком 8; при ширине 375 их ширина 171,5.
Переключатель срока: радиус 16, внутренний отступ 4, кнопки высотой 40.
Нижняя панель: радиус 24, кнопка высотой 56, цвет `#4D5CFF`.
Панель учитывает safe area; содержимое прокручивается над ней.
Системная строка состояния на телефоне остаётся системной, не рисуется из макета.

## Проверки

- 61 серверный тест: каталог, токены, выбранный ID тарифов, отказ при чужом ID
  в ответе, пустой список, 404/422, обновление токена и некорректные данные.
- 14 клиентских тестов: цены, валюты, сроки, фильтрация, сортировка, выбор,
  безлимит, единицы объёма и заголовки.
- TypeScript и экспорт OpenAPI/JSON Schema прошли.
- Живой FastAPI вернул HTTP 200 для Турции (11 тарифов), ОАЭ (8), Франции (11),
  Бразилии (10), Новой Зеландии (11).
- Для Турции доступны 1, 7, 15, 30 дней. На 15 дней API вернул 5 ГБ за 439 RUB
  и безлимит за 1819 RUB — экран использует эти значения, а не цены из макета.
- Web-, iOS- и Android-сборки прошли. Браузерная визуальная проверка и проверка на физическом
  телефоне не выполнены: CUA сообщил `No browser is available`.
