# Общий нижний таб-бар

`apps/mobile/src/components/FloatingTabBar.tsx` используется существующим
MainTabs на всех пяти вкладках. Внешний вид сверён с Figma `475:12063`
внутри главной `475:11924`.

При экране 375×812 контейнер занимает x=12, y=724, 351×64 pt.
Радиус — 24, сглаживание — 60%, padding — 6, gap — 2.
Равные кнопки имеют высоту 52; выбранная плашка — радиус 18,
фон плашки — отдельный размытый материал. Подписи — 12/14; акцент — #808FFF,
неактивный цвет — белый 50%. По уточнению пользователя форма сохранена,
а оформление возвращено к iOS-стилю предыдущего варианта.
На iOS, Android и вебе используются общие локальные SVG для активного и
неактивного состояний каждой вкладки.

Нижний отступ на вебе — 24 pt; на устройстве —
`max(24, safeAreaBottom - 10)`. При safe area 34 получается положение
макета. Боковые отступы — 12 плюс safe area. Отступ прокрутки экранов
рассчитывается через общий getTabBarBottom.

По последнему уточнению iOS-стекло сохранено, удалена только декоративная
жёлтая кромка: цветной подсветки и inset-теней нет.
На совместимой iOS-сборке используется GlassView regular/dark.
Тёмный tint усилен с 15% до 28%, чтобы фон меньше просвечивал.
Без нативного модуля стекла используется systemUltraThinMaterialDark
с усиленной интенсивностью 88 вместо 80.
На вебе установлен `liquid-glass-react` 1.1.1 из
[rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react).
Компонент используется только через TabBarMaterial.web.tsx; на Android — непрозрачный фон.
Reduce Transparency заменяет стекло непрозрачным фоном #212124.
Выбранная плашка использует BlurView на iOS и backdrop blur на вебе.
Отдельный GlassView у плашки убран, чтобы он не создавал отражений и бликов.
Её фон прозрачный; на Android и при
Reduce Transparency используется #38383C. Плашка перемещается в native
Animated.View без MaskedView / CSS clip-path, чтобы размытие оставалось живым.
По образцу пользователя заливка плашки стала легче: белый 10% на вебе
и нейтральный белый слой 10% на iOS. Blur на вебе отделён от заливки:
Библиотека настроена на blurAmount 0.125 (8 px), saturation 140,
displacementScale 40 для меню и 0 для плашки. Её эластичность отключена:
переключением управляет существующая пружина приложения. У плашки нет
блика, градиента и светящейся тени.
Scoped CSS-адаптер задаёт размеры внутренней .glass и отключает стандартные
яркие border/light-слои библиотеки без установки Tailwind. При изменении
размеров материал пересоздаётся по ResizeObserver. До первого измерения
действует CSS blur, при Reduce Transparency — непрозрачный фон.
В Firefox библиотека сама отключает SVG displacement: остаются blur и tint.
Это ограничение подтверждено README библиотеки и проверено в Firefox.
Контейнер не использует MaskedView / CSS clip-path, чтобы материал
получал живой фон экрана. Сохранены форма, размеры и внешняя тень
0/10/30 rgba(18,15,36,0.1). Отдельной полосы под меню на главной нет.
По всему внешнему контуру добавлена едва заметная белая обводка:
0,5 pt, rgba(255,255,255,0.12). Она рисуется отдельным слоем поверх
материала, не меняет размеры кнопок и пропускает нажатия.

Индикатор использует Animated.spring: stiffness 420, damping 36, mass 1.
На iOS/Android translateX выполняется нативным драйвером, на вебе — JS.
Ширина берётся из layout и не анимируется нативным драйвером.
Повторное измерение и возврат из stack синхронизируют положение сразу.
Reduce Motion отключает пружину. Настройка слушается во время работы приложения.

Сохранены параметры маршрутов, tabPress с возможностью отмены,
tabLongPress и состояние текущей вкладки. Кнопки сообщают VoiceOver
название и выбранное состояние. Нажатие активной вкладки не создаёт её заново.

tab-navigation.test.mjs проверяет пять состояний, параметры и отмену
переходов, возврат из stack, драйвер пружины, Reduce Motion/Transparency,
материалы iOS и общие SVG-иконки. Проверены TypeScript, клиентские тесты
и экспорты web/iOS/Android. Экспорт JavaScript не заменяет сборку Xcode;
физический iPhone в этой сессии недоступен.

Материал проверен в Chromium и Firefox при 375×812: библиотека смонтирована
у меню и выбранной плашки, blur 8 px, светящиеся слои скрыты, геометрия
и иконки сохранены. В Chromium SVG filter включён, в Firefox — отключён.

`apps/mobile/qa/rdev-liquid-glass-firefox.png`.
