# Экран «Весь мир»

Карточка в каталоге и подбор на главной открывают отдельный экран по [макету Figma 415:14198](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=415-14198).

Верхняя зона повторяет градиент макета и содержит круглые кнопки «Назад» и «Поделиться» с общим материалом таб-бара. Используются иконки Figma 20 × 20 и оригинальный стикер «мир» 80 × 41. Нативная кнопка «Поделиться» открывает системное меню с выбранным тарифом. В браузере доступен текст для копирования.

Сроки, пакеты и цены загружаются через `GET /api/catalog/esims/{id}/tariffs` для глобальной eSIM с кодом `XG`. Если доступны 7 дней и 3 ГБ, они выбираются по умолчанию. Параметры поездки имеют приоритет. Нижняя панель показывает текущую цену, объём и срок. «Купить» открывает оформление для выбранного пакета.

Чипы и кнопка «ещё» используют страны действующего каталога. Точное покрытие глобального пакета требует подтверждения поставщика. Окно со списком содержит соответствующую подпись.
