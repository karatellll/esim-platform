# Экран категории / региона

Реализовано 15 октября 2026 года. Источник дизайна:
[Figma, «Регион · Европа», 91:5136](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=91-5136).
Получены высокодетальный контекст и изображение экрана.

## Сценарий

`Страны → Регионы → карточка категории` открывает `RegionTariffsScreen`
в native stack без таб-бара. Работают кнопка назад, отправка текста предложения,
чипы стран, «ещё N» со списком и поиском, переход к тарифам отдельной страны,
выбор срока и регионального тарифа. Кнопка внизу показывает выбранную цену.
Как на экране страны, «Купить» пока открывает сведения о выбранном тарифе
и сообщение о будущей доступности покупки; заказ и оплата не выполняются.

Данные категории передаются из уже загруженного SDK-каталога. Региональные
тарифы читаются через существующий серверный маршрут:

```text
GET /api/catalog/esims/{regional_esim_id}/tariffs
 → GET /v1/sdk/esims/{regional_esim_id}/tariffs
```

Сервер переиспользует ClientToken и обновляет его при необходимости.
Новых ключей, маршрутов, схем или изменений базы данных не требуется.

## Выбор регионального пакета

Поиск выполняется только среди подтверждённых региональных кодов
`XS`, `XA`, `XM`, `XC`, `XE`, `XB`, `XN`, `XL`. Приоритет имеет совпадение названия
пакета с названием категории после удаления пометки `(регион)`. Если совпадения
нет, единственный региональный пакет категории можно открыть под его настоящим
названием. Если кандидатов несколько и совпадения нет, случайный пакет не выбирается.
Страна и глобальный `XG` не подставляются вместо региональной eSIM.

В текущем каталоге:

| Категория | Выбранный пакет | Минимальная цена SDK |
|---|---|---|
| Европа | `XE`, Европа | 139 RUB |
| Азия | `XS`, Азия | 309 RUB |
| Северная Америка | `XN`, Северная Америка | 179 RUB |
| Южная Америка | `XL`, Латинская Америка | 219 RUB |
| Африка, Океания, Популярное | Регионального пакета нет | Предлагаются отдельные страны |

Для Южной Америки выводится отдельная подпись «Тарифы пакета “Латинская Америка”».
На карточке категории с региональной eSIM показана минимальная цена именно
этого пакета; для остальных категорий сохраняется минимум отдельных направлений.

## Страны и точность данных

В ответах SDK-каталога и региональных тарифов проверены только группы, элементы,
пакет и тарифы. **Точного списка стран покрытия региональной eSIM там нет.**
Поэтому чипы и счётчик подписаны как страны категории. Текст из макета
«Одна eSIM на 39 стран» не подставляется как подтверждённое покрытие.
У категории Европы сейчас 43 уникальные страны; это не утверждение, что `XE`
покрывает каждую из них. Перед подключением покупки нужно получить список покрытия.

Первые пять чипов используют существующие страны категории. Для Европы порядок
Франция, Италия, Германия, Испания, Бельгия взят из макета. Отсутствующие в API
страны не добавляются. Остальные доступны через «ещё N», поиск по названию и ISO.
Пакеты исключены из чипов стран, дубли по стране удалены.

Сроки и карточки тарифов выводятся только из ответа конкретного пакета.
Переиспользуется логика экрана страны: 15 дней при наличии, иначе короткий срок;
предпочтение тарифу с флагом выгоды, затем 5 ГБ, затем первому тарифу.
Безлимит отображается только при соответствующем признаке нормализованного ответа.
Цены используют принятую шкалу каталога без деления на 100.

## Дизайн и ресурсы

- Оригинальный стикер слоя `91:5147` скачан в
  `apps/mobile/assets/regions/title-sticker.svg`: исходный размер 120 × 41,
  поворот 1,5°. Длинные названия адаптируют ширину через transform.
- `back.svg` и `share.svg` из `assets/tariffs` — точные совпадения SVG
  `8905f.svg` / `a63a1.svg` из контекста, размер 20 × 20 в кнопках 40 × 40.
- Флаги 24 × 24 берутся из API; статические страны из макета не зашиты в экран.
- Чипы высотой 32, радиусом 16, промежутком 6; основной отступ 12.
- Переключатель срока: радиус 14, отступ 4, кнопки высотой 36 и радиусом 10.
- Тарифы: вертикальный список, отступы 16, радиус 20, промежуток 8;
  выбранная строка обведена `#4D5CFF` толщиной 2.
- Нижняя кнопка: высота 56, радиус 16, отступы 12, учитывается safe area.
- Системный статус-бар на телефоне остаётся системным.

## Проверка

21 клиентский тест прошёл: денежные поля, выбор регионального пакета, отсутствие
подмены страной/глобальным пакетом, неоднозначные категории, реальные чипы,
сроки, выбор тарифа и форматирование. TypeScript прошёл.
Сборки web, iOS и Android прошли; локальные SVG проверены по размерам и ссылкам
из компонентов. Значения серверных ключей отсутствуют в web-бандле.

Живой FastAPI вернул HTTP 200 для `XE`, `XS`, `XN`, `XL`. Для Европы на 15 дней
получены 5 ГБ за 569 RUB и безлимит за 2779 RUB. Серверный контракт не менялся.
Визуальная проверка в браузере недоступна: CUA вернул пустой список браузеров;
проверка на физическом устройстве не выполнена.
