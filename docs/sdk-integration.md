# Подключение SDK API поставщика

Обновлено 15 октября 2026 года. Чтение каталога через SDK реализовано.

```text
React Native → GET /api/catalog/categories (наш FastAPI)
             → POST /v1/partner/client-tokens (при необходимости)
             → GET /v1/sdk/esims
```

## Настройки

Корневой серверный `.env`:

```dotenv
ESIM_PROVIDER_BASE_URL=https://esim-api.terexov-tech.ru
ESIM_PARTNER_TOKEN=sk_live_ваш_партнерский_ключ
ESIM_PUBLISHABLE_KEY=pk_live_ваш_публичный_ключ
ESIM_CATALOG_EXTERNAL_USER_ID=tursim-catalog
ESIM_REQUEST_TIMEOUT_SECONDS=15
```

Сервер читает обе настройки ключей. В текущем локальном `.env` они уже заданы.
После изменения настроек или кода перезапустите сервер: `npm run api`.
Действующие ключи в документацию не записываются.

## Выпуск и обновление ClientToken

Проверен живой запрос:

```http
POST https://esim-api.terexov-tech.ru/v1/partner/client-tokens
Authorization: Bearer <партнерский ключ sk_live_…>
Content-Type: application/json
Idempotency-Key: <UUID конкретного выпуска>
```

```json
{"external_user_id": "tursim-catalog"}
```

Поставщик вернул HTTP 200 и структуру:

```json
{
  "data": {
    "token": "<ClientToken>",
    "jti": "<идентификатор>",
    "expires_at": "<дата и время с часовым поясом>"
  },
  "request_id": "<идентификатор запроса>"
}
```

Сервер берёт срок действия из `data.expires_at`, хранит токен только в памяти
и переиспользует его для чтения каталога. Новый токен выпускается при первом
обращении и при следующем обращении перед истечением: за 60 секунд либо за
10% оставшегося при выпуске срока для коротких токенов.
Если SDK возвращает 401 с `token_expired`, `token_revoked` или `invalid_token`,
сервер получает замену и повторяет чтение один раз. Бесконечного повтора нет.
Одновременные запросы разделяют один выпуск в пределах процесса.

Для нового выпуска создаётся новый `Idempotency-Key`; при сетевой ошибке,
таймауте или ошибке поставщика повтор сохраняет ключ незавершённого выпуска.
После перезапуска процесса память токена и ключа очищается; каждый worker
имеет собственный кэш. `ttl_seconds` не передаётся: ограничения этого параметра
и срок по умолчанию не закреплены контрактом проекта.

`ESIM_CATALOG_EXTERNAL_USER_ID` — отдельная служебная идентичность только
для чтения каталога. Приложение не может выбрать её через параметры запроса.
Ключи и ClientToken не передаются мобильному клиенту и не записываются в логи.

**Покупки и персональные SDK-запросы требуют отдельных пользовательских сессий.**
Для них ещё нужно определить идентификацию гостей и зарегистрированных
пользователей, выпускать токен с их стабильным `external_user_id` и проверять
доступ. Служебный токен каталога нельзя использовать для пользовательских заказов.

## Подтверждённый SDK-каталог

```http
GET https://esim-api.terexov-tech.ru/v1/sdk/esims
Authorization: Bearer <ClientToken>
X-Publishable-Key: <публичный ключ pk_live_…>
```

15 октября живой запрос с обоими заголовками вернул HTTP 200.
Ответ содержит `data: [{title, items: [...]}]` и `meta.has_more: false`.
В элементах проверены поля `id`, `country`, `name`, `phone_code`, `image_url`,
`photo_url`, `min_price_amount`, `min_price_currency`.

Для совместимости с экраном наш сервер преобразует `items` в `esims`,
`country` в `country_iso2`, `name` в `display_name`; сохраняет `id`, `image_url`,
`min_price_amount`, `min_price_currency` и известные поля `meta`.
Цены передаются без пересчёта. В интерфейсе сумма отображается напрямую:
`199 RUB` → «от 199 ₽». Нулевое значение допустимо; отсутствующая цена/валюта
отображается как «—». Для карточки категории выбирается минимум вложенных
направлений в одной валюте; разные валюты не сравниваются.
Подпись глобального пакета берёт цену записи `country=XG` вместо цены из макета.
Нажатие карточки выбирает вкладку «Весь мир» по Figma `103:49480`;
её тарифы используют SDK ID той же записи. [Описание вкладки](world-screen.md).
Проверены глобальные тарифы: 10 ГБ / 30 дней за 3939 RUB, 20 ГБ / 90 дней
за 6499 RUB, 40 ГБ / 180 дней за 10049 RUB, 80 ГБ / 365 дней за 19489 RUB.
В проверенном ответе тарифов ОАЭ то же число 199 названо `price_amount_minor`;
единицы каталога отображаются по принятому выше правилу, без деления на 100.
Остальные поля не передаются.
Категории берутся из SDK; старый `GET /v1/partner/catalog/categories` не вызывается.

## Ручная проверка в Postman

Для выпуска используйте партнёрский ключ в POST выше и новый UUID в
`Idempotency-Key`. Затем скопируйте `data.token` в Authorization → Bearer Token
запроса `GET /v1/sdk/esims`, добавьте `X-Publishable-Key`, Body → none.
Не добавляйте слово `Bearer` в поле Token: Postman добавляет его сам.
Истёкший ClientToken заменяется новым выпуском; постоянной настройкой `.env`
он не является.
