# Мобильная навигация

Реализована 13 октября 2026 года по
[Figma «F · Главная»](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=38-4518).

## Источники

- Главная / поиск: таб-бар `38:4588`.
- Страны: таб-бар `38:4716`.
- Мои eSIM: таб-бар `38:5915`.
- Копилка: таб-бар `38:5333`.
- Профиль: таб-бар `38:6009`.

Для всех пяти состояний получены кодовые параметры и скриншоты Figma.
Иконки скачаны в `apps/mobile/assets/tab-bar`; временные URL Figma не
используются приложением. Исходные SVG сохранены без изменения.

## Параметры

- Фон экрана: `#141416`.
- Подложка таб-бара: `#212124`, высота 64, скругление 24, отступы по бокам 12.
- Внутренний отступ: 6; высота кнопки 52, скругление 18.
- Активная подложка: `#38383C`; активный текст и иконка: `#808FFF`.
- Неактивный текст: белый с прозрачностью 50%; иконки соответствуют SVG макета.
- Ширина таб-бара не более 351, он центрирован на всех вкладках. Пять кнопок
  равной ширины с промежутком 2; при исходной ширине 351 каждая занимает 66,2.
  Выбор вкладки не меняет размеры и положение таб-бара и его кнопок.
- Иконки: 22 × 22. Подписи: размер 12, высота строки 14, насыщенность 500.
- На исходном экране 375 × 812 низ таб-бара находится на высоте 776:
  нижний отступ 36 включает системную область home indicator.

На устройствах используется фактическая безопасная область. В браузерном
предпросмотре нижний отступ составляет 36, как в макете. Системные статус-бар
и home indicator не рисуются внутри приложения.

## Анимация выбора вкладки

Активная серая подложка — один абсолютный `Animated.View` под кнопками.
При смене вкладки её позиция и ширина меняются за 240 мс с замедлением
`Easing.out(Easing.cubic)`. Размеры и координаты берутся из `onLayout`
реальных кнопок при изменении ширины окна. На всех вкладках геометрия одинакова;
при переключении перемещается только активная подложка.
При быстром переключении предыдущее движение останавливается на текущем
значении, следующее начинается от него. При первом показе и системной
настройке уменьшения движения подложка устанавливается без анимации.
Анимация запускается только при смене ключа выбранной вкладки, пока основной
экран в фокусе. Открытие категории завершает текущее движение установкой
подложки в конечное положение; возврат из категории и повторные измерения
той же вкладки не запускают анимацию. Нулевые размеры скрытого таб-бара
игнорируются, чтобы сохранять последнюю корректную геометрию.
Только подложка анимируется: цвета иконок и подписей меняются вместе
с выбранной вкладкой. Сжатие иконок и тактильный отклик не добавлялись.

## Размытие при прокрутке

По просьбе пользователя добавлен плавный переход под таб-баром: слой начинается
строго на его верхней границе и постепенно усиливает размытие и затемнение
в течение следующих 48 pt. Выше таб-бара размытия нет; слой обрезан по своей
границе. Сам таб-бар и его кнопки остаются чёткими. Слой не перехватывает касания.

В браузере используется `backdrop-filter: blur(16px)` с градиентной маской.
На iOS/Android — `expo-blur` с градиентной маской `MaskedView`. Каждый экран
обёрнут в отдельный `BlurTargetView`, активная цель передаётся в таб-бар, как
предусмотрено [документацией Expo для Android](https://docs.expo.dev/versions/latest/sdk/blur-view/#android-support).
Это позволяет размывать актуальный список после переключения вкладок.

Проверены браузерный эффект, прокрутка через область перехода, боковые буквы,
все пять вкладок и возврат на экран, высоты 568/812/844. TypeScript и экспорт
web/iOS/Android прошли. Нативный вид эффекта на физическом устройстве ещё не проверен.

## Объём реализации

Пять маршрутов с рабочим переключением. Начальная вкладка — «Поиск».
Во вкладке «Страны» реализованы экран направлений и переключатели стран/регионов/всего мира.
Во вкладке «Профиль» добавлен [экран гостя](profile-guest-screen.md) по Figma `91:5676`.
«Поиск», «Мои eSIM» и «Копилка» пока пустые. Каталог и тарифы подключены
через собственный сервер; покупки и вход по почте будут реализованы отдельно.

## Все направления

Источник: [F · Все eSIM, 38:4622](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=38-4622).
Реализованы верхняя часть и алфавитный список стран из категорий API:

- «Все направления» с оригинальной синей подложкой стикера.
- Поле «Страна или регион»: фильтрация загруженных стран по названию и ISO-коду.
- «Страны / Регионы / Весь мир»: локальное переключение выделения.
- Зелёная карточка «Одна eSIM на все поездки»: переключает раздел на «Весь мир»
  по Figma `103:49480`. Цена карточки и тарифы вкладки используют SDK-запись `XG`.
  Нижний таб-бар остаётся видимым; подробности в [world-screen.md](world-screen.md).

Из Figma получены исходные SVG стикера, поиска, глобуса и стрелки.
Список стран подключён к категориям собственного API. Источник данных и
проверка описаны в [catalog-api.md](catalog-api.md). Страны объединены без дублей,
сгруппированы по буквам и отсортированы по русскому алфавиту. Боковой указатель
синий, шириной 13, на исходном экране начинается на высоте 300; на коротких
экранах его положение и высота адаптируются. Нажатие прокручивает список к букве.

Раздел «Регионы» реализован по [3.1 · Регионы, 38:7996](https://www.figma.com/design/PWdKnO2WHAIS0NE18vlgL4/?node-id=38-7996).
На нём нет поиска и зелёной карточки. Карточки категорий имеют высоту 120,
скругление 24, отступ по бокам 12 и промежуток 12. Первая карточка начинается
на высоте 169.639. Названия, количество стран и флаги взяты из API.
Оригинальные фотографии Европы и Азии скачаны в `assets/regions`; для остальных
категорий совпадающих фотографий нет, поэтому используется однотонная подложка.
Минимальная цена страны берётся из `min_price_amount` и `min_price_currency` SDK;
цена категории — минимум вложенных направлений в одной валюте. Формат —
«от 199 ₽» для значения `199 RUB`, без деления на 100; при отсутствии цены — «—».

На экране 375 × 812 контент начинается в `(16, 60)`, поле поиска имеет
размер 331 × 52 и находится на высоте 125.639, карточка — 331 × 70.
Проверены ввод текста, три выбранных состояния, неактивная карточка,
локальные ресурсы на ширинах 320, 375 и 430. Прямые запросы к Partner API
выполняет только собственный сервер.

## Проверка

- TypeScript: `npm run typecheck` — успешно.
- Metro экспорт для браузера, iOS и Android — успешно. Это проверка сборки
  JavaScript и ресурсов, а не установка приложения на устройство.
- В отдельном тестовом браузере проверены все пять вкладок, пустые экраны,
  активные иконки, единственное выбранное состояние и отсутствие ошибок выполнения.
- При размере 375 × 812 таб-бар занимает `(12, 712, 351, 64)`, как в Figma.
  Проверены также ширины 320 и 430; все кнопки остаются внутри таб-бара.
- Иконки таб-бара имеют исходный размер 22 × 22 и отображаются с таким же размером.
- Проверены 147 уникальных стран, переходы по буквам, поиск, 7 карточек регионов,
  геометрия карточек из Figma и положение указателя на высотах 568, 812 и 844.
- Запуск на физическом iOS/Android-устройстве пока не проверен.

`npm audit` сообщает о 22 предупреждениях в дереве зависимостей Expo / React Native
(7 moderate, 15 high), включая инструменты сборки. Предложенное автоматическое
исправление части дерева требует несовместимого отката Expo; такой откат не выполнен.
