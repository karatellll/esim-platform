## Данные и ограничения

`SDKCatalogItem` и наш `CatalogEsim` теперь передают `network` и `photo_url`
из `sdk.esimRefDTO` / `sdk.tariffsEsimDTO` предоставленного `doc.json`.
Поля необязательные и nullable. Они проходят через категории, тарифы и
персональный расчёт заказа. Фото поставщика используется как динамический
источник; при отсутствии есть локальные ресурсы. Строка сети выводится
только при наличии значения. Живая проверка 30 октября: 160 записей, фото
есть у 160, сеть не заполнена ни у одной. Пример Swagger с 5G не является
фактической сетью страны и в интерфейс не подставляется.

Состав географической категории не равен покрытию регионального или
глобального пакета. Подтверждённого метода покрытия в предоставленном
Swagger нет. Поэтому шторка «Весь мир» называется «Страны каталога» с
пояснением «Покрытие пакета нужно уточнить», показывает реальные направления
и открывает их индивидуальные тарифы. Шторка региона явно называет категорию.
Точное покрытие по макету «Одна eSIM на все эти страны» пока не подключено.

Маршрутов/полей погашения промокода в SDK-расчёте и создании заказа не найдено.
`POST /api/checkout/summary` с непустым `promo_code` по-прежнему возвращает
422 `promo_unavailable` до обращения к поставщику. Код `SUMMER` из макета
не является рабочей скидкой. Клиент выводит реальную ошибку доступности,
не подменяет её утверждением о недействительном коде.

В собственный контракт расчёта добавлено nullable `promotion`:
`code`, `subtotal_amount`, `discount_amount`. Сейчас сервер возвращает null.
Положительный ответ принимается клиентом только с этим подтверждением;
серверная модель требует персональную котировку и согласованность суммы.
Для включения погашения ещё нужны подтверждённый контракт поставщика,
передача скидки в расчёт/создание заказа, сохранение в котировке и проверка
фактической суммы кассы. Локальная скидка без изменения суммы оплаты
не создаётся. Изменений базы для текущего поведения не требуется.

Проценты в каталоге вычисляются из стоимости ГБ относительно самого
малого пакета того же срока и валюты. Это выгода за объём, а не промокод.
Безлимит, неизвестные единицы и несопоставимые цены исключаются из расчёта.

Ссылка «Напишите нам» открывает существующую поддержку приложения.
Ограничение поддержки сохранено: оператор ещё не подключён, сообщения
сохраняются в аккаунте и не выдаются за отправленные оператору.

## Проверки и запуск

- `npm run typecheck`.
- `npm run test:catalog`, включая новые сценарии промокода и списка стран.
- `apps/api/.venv/bin/python -m pytest apps/api/tests -q`.
- `npm run contracts` — обновлены JSON Schema/OpenAPI и TypeScript-контракт.
- `npm --prefix apps/mobile run export:web`.
- Из `apps/mobile`: `node_modules/.bin/expo export --platform android --output-dir /tmp/catalog-promo-android-export`.
- Запущенные Expo `http://localhost:8081` и API `http://localhost:8000`
  проверены HTTP-запросами. Команды запуска: `npm run api` и `npm run web`
  в разных терминалах; настройки описаны в README приложений.

Проверены исходные размеры и слоты оригинальных ресурсов шторок, фото и
глобуса. Экспортированные SVG сохраняют размеры корневых элементов.
Клавиатура системная, её изображение из макета в приложение не переносится.
Браузер и эмулятор в среде проверки недоступны; сборки и компонентные
сценарии проверены, визуальное сравнение готового экрана на устройстве
не выполнено. Реальный платёж не проводился.
