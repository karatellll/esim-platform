# Категории и страны SDK-каталога

Обновлено 15 октября 2026 года:

```text
React Native → GET /api/catalog/categories (наш FastAPI)
             → POST /v1/partner/client-tokens (когда нужен токен)
             → GET /v1/sdk/esims (поставщик)
```

Страны и категории загружаются из SDK. Старый Partner API категорий больше
не вызывается. Мобильный клиент сохраняет собственный маршрут и формат
ответа: `data: [{title, esims: [{id, country_iso2, display_name, image_url,
min_price_amount, min_price_currency}]}]`.
Сервер преобразует проверенный SDK-формат `items/country/name` в этот контракт.
Неизвестные поля и ошибки поставщика не пересылаются клиенту.

## Авторизация

Нужны `ESIM_PARTNER_TOKEN` и `ESIM_PUBLISHABLE_KEY` в корневом серверном `.env`.
Первый ключ используется для выпуска ClientToken, второй вместе с ClientToken
передаётся в SDK-запросе. Срок действия берётся из `data.expires_at`.
Токен автоматически переиспользуется, обновляется перед истечением и один раз
перевыпускается при ошибке истечения/отзыва/недействительного токена SDK.
Выпуск защищён блокировкой и использует `Idempotency-Key`.

Служебная идентичность `ESIM_CATALOG_EXTERNAL_USER_ID=tursim-catalog` предназначена
только для каталога. Пользовательские заказы через неё не реализуются.
Ключи и токен остаются в серверной памяти. База для этой функции не нужна.
Подробности и ограничения: [sdk-integration.md](sdk-integration.md).

## Экран и контракт

- «Страны»: записи категорий объединяются по `country_iso2`, сортируются
  по русскому алфавиту; работают поиск и боковой указатель букв.
- Специальные коды пакетов `XG`, `XS`, `XA`, `XM`, `XC`, `XE`, `XB`, `XN`, `XL`
  исключены из стран; `XK` (Косово) сохранено.
- «Регионы»: отображаются категории SDK. Европа и Азия используют существующие
  фотографии макета. Количество стран считается после исключения пакетов и дублей.
- Карточка категории открывает [экран региона](regions-api.md). Если есть
  региональная eSIM, на карточке показывается её минимальная цена; иначе —
  минимум отдельных направлений. Подмена регионального пакета страной исключена.
- Пустой ответ, отсутствие результатов поиска, загрузка и ошибка с повтором
  обрабатываются существующим экраном.
- Изображения поступают из API; при отсутствии/ошибке флага показывается ISO-код.
- Минимальные цены берутся из `min_price_amount` и `min_price_currency` SDK,
  отображаются напрямую: `199 RUB` → «от 199 ₽». В категориях показывается
  наименьшая цена вложенных направлений в одной валюте. Отсутствующая цена — «—»;
  разные валюты не сравниваются. При дублях страны выбирается более дешёвая
  запись в той же валюте. Цена глобального пакета берётся из записи `XG`.
- Нажатие страны открывает [экран тарифов](tariffs-api.md), загружаемый из
  `GET /v1/sdk/esims/{id}/tariffs`. Карточка глобального пакета переключает
  раздел на [«Весь мир»](world-screen.md) с реальными тарифами XG.
- Таймаут клиента увеличен до 65 секунд: холодная загрузка включает выпуск
  токена, а отказ SDK может потребовать перевыпуска и одного повтора.

Схемы: `packages/shared/contracts/catalog.schema.json`, `openapi.json`, `catalog.ts`.
Собственный `/docs` описывает SDK-источник данных; публичный контракт сохранился.

## Проверка

Проверены живые ответы HTTP 200 выпуска ClientToken и SDK-каталога.
Ответ SDK сгруппирован: `data[].title` и `data[].items`; `meta.has_more=false`.
Полная спецификация поставщика пока недоступна (401).

50 серверных тестов и 7 клиентских тестов цен прошли. Автотесты проверяют выпуск/переиспользование токена, срок действия, однократный
повтор при 401, конкурентные обращения, сохранение Idempotency-Key после сбоя,
правильные заголовки, преобразование каталога, ошибки сети/доступа, редиректы,
некорректные ответы, отсутствие утечки ключей и CORS.

Сквозная проверка через FastAPI с реальным поставщиком вернула HTTP 200:
7 категорий, 160 записей, 147 уникальных стран без региональных пакетов.
На два чтения пришлись один выпуск токена и два `GET /v1/sdk/esims`;
старый маршрут категорий не вызывался. Проверка TypeScript, экспорт контрактов
и web-сборка прошли. Живой FastAPI возвращает цены всех 160 записей:
ОАЭ — 199 RUB, минимум Азии — 89 RUB. Значения ключей ранее не обнаружены в web-бандле.
Дизайн экрана не менялся; запуск на физическом устройстве повторно не проверялся.
