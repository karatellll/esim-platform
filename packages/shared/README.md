# Общие контракты

В `contracts/` хранятся OpenAPI собственного API, JSON Schema ответа категорий
и тарифов, а также TypeScript-типы этих ответов, которые импортирует мобильный клиент.

Команда `npm run contracts` экспортирует OpenAPI и JSON Schema из моделей FastAPI.
При изменении этих моделей синхронно обновляйте `catalog.ts`.

Код и секреты серверной интеграции с поставщиком сюда не помещаются.
