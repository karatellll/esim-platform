# Мобильное приложение

Клиент «ТурСим» для iOS и Android на React Native + TypeScript с запуском через Expo.
Навигация — React Navigation, иконки — локальные оригинальные SVG из Figma.

## Что реализовано

Пять вкладок: «Поиск», «Страны», «Мои eSIM», «Копилка», «Профиль».
Во вкладке «Страны» открывается экран «Все направления»: заголовок со стикером,
поле «Страна или регион», переключатели «Страны / Регионы / Весь мир» и зелёная
карточка «Одна eSIM на все поездки». При открытии экран загружает категории
через наш FastAPI из `GET /v1/sdk/esims` и показывает страны с названиями и
изображениями поставщика. ClientToken выпускается и обновляется на сервере.
Поиск фильтрует загруженные страны; при ошибке доступна кнопка «Повторить».
Страны объединяются без дублей, сортируются по русскому алфавиту и сгруппированы
по начальной букве. Боковой указатель прокручивает список к выбранной букве.
Глобальные и региональные пакеты исключены из списка стран; Косово сохранено.
На переключателе «Регионы» показаны категории API карточками по Figma:
Европа и Азия с оригинальными фотографиями, остальные — без фоновых картинок.
Карточка открывает экран региона по Figma `91:5136`: страны с поиском,
доступные сроки и тарифы региональной eSIM, выбор пакета и кнопка с его ценой.
Если регионального пакета в категории нет, можно выбрать отдельную страну.
Страны подписаны как состав категории: точное покрытие пакета API не возвращает.
Подробнее: [regions-api.md](../../docs/regions-api.md).
Карточка «Одна eSIM на все поездки» переключает раздел на «Весь мир».
Он реализован по Figma `103:49480`: карточка с глобусом, сроки, список тарифов XG
и кнопка с выбранной ценой; нижний таб-бар остаётся видимым.
Цены и сроки приходят из API; при отсутствии XG доступен повтор загрузки.
По просьбе пользователя подпись «120+ стран», флаги и «+114» повторяют макет;
тарифы и цены загружаются из API. Сам список покрытия пока недоступен.
Подробнее: [world-screen.md](../../docs/world-screen.md).
Минимальные цены стран и категорий подключены к `min_price_amount` и
`min_price_currency`: например, `199 RUB` отображается как «от 199 ₽» без
пересчёта единиц. Для категории берётся минимум вложенных направлений в одной
валюте; при отсутствии цены показано «—».
Нажатие страны открывает экран «Страна · тарифы» по Figma `64:3926`.
Доступные сроки и пакеты приходят из SDK; работают выбор срока/пакета,
пересчёт итоговой цены, возврат в каталог и отправка текста предложения.
«Купить» пока показывает выбранный тариф и сообщение о будущей доступности покупки.
Подробнее: [tariffs-api.md](../../docs/tariffs-api.md).
Во вкладке «Профиль» реализован экран «Профиль · гость» по Figma `91:5676`:
заголовок со стикером, кнопка входа, карточки «Помощь» и «О сервисе», версия.
Оригинальные SVG находятся в `assets/profile`. Вход, инструкция, поддержка
и юридические документы пока не подключены; кнопки показывают сообщения
о недоступности. Подробнее: [profile-guest-screen.md](../../docs/profile-guest-screen.md).
Экраны «Поиск», «Мои eSIM» и «Копилка» пока пустые.

На старте выбрана вкладка «Поиск». Таб-бар сохраняет активное состояние и учитывает безопасную
область устройства. На Android кнопка «Назад» возвращает к предыдущей вкладке.
При прокрутке контент под таб-баром плавно размывается и затемняется.
Кнопки таб-бара остаются чёткими; слой эффекта пропускает касания к списку.

## Запуск

Из этой папки:

```bash
npm ci
npm start
```

В Expo Go отсканируйте QR-код. Телефон и компьютер должны быть в одной сети;
версия Expo Go должна поддерживать SDK, указанный в `package.json`.

- `npm run android` — открыть на подключённом Android-устройстве или эмуляторе.
- `npm run ios` — открыть iOS Simulator на macOS.
- `npm run web` — проверить интерфейс в браузере.
- `npm run typecheck` — проверить типы.
- `npm run test:catalog` — проверить цены каталога (проверено с Node.js 24).
- `npm run export:web` — собрать браузерную версию для проверки.

Для загрузки каталога запустите сервер командой `npm run api` из корня репозитория.
Партнёрский и публичный ключи (`ESIM_PARTNER_TOKEN`, `ESIM_PUBLISHABLE_KEY`)
задаются в корневом серверном `.env`; клиент получает только данные каталога.

В браузере API по умолчанию доступен на текущем hostname и порту 8000.
В Expo Go hostname берётся из конфигурации сервера Expo, поэтому телефон
и компьютер должны быть в одной сети. Для туннеля Expo или удалённого сервера
задайте `EXPO_PUBLIC_API_URL` в локальном `apps/mobile/.env`; после изменения
этого адреса перезапустите Expo. В production адрес API задаётся явно.

## Структура

```text
App.tsx                      # Тема, safe area, навигация
src/navigation/              # Вкладки и навигатор
src/components/              # Таб-бар, страны, регионы и алфавитный указатель
src/catalog/                 # Объединение, сортировка и фильтрация стран
src/screens/                 # Экран направлений и остальные маршруты
src/theme.ts                 # Цвета и размеры Figma
assets/tab-bar/               # Пять иконок в двух состояниях
assets/regions/               # Оригинальные фотографии регионов из Figma
src/api/                     # Клиент собственного API
src/hooks/                   # Загрузка и отмена запросов при уходе с экрана
```

Источник дизайна и параметры: [mobile-navigation.md](../../docs/mobile-navigation.md).
На iOS используется системный SF Pro, на Android — системный шрифт платформы.
В браузере для заголовка «Все направления» используется Arial с адаптированным
межбуквенным интервалом, чтобы текст помещался в исходный стикер Figma.
