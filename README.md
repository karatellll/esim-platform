# esim-platform

Монорепозиторий проекта «ТурСим»: мобильное приложение для iOS/Android,
собственный бэкенд и контракты обмена данными.

## Структура

```text
apps/
  mobile/              # React Native + TypeScript + Expo
    src/               # Экраны, навигация, компоненты и тема
    assets/tab-bar/    # Оригинальные иконки Figma
  api/                 # Бэкенд на Python + FastAPI
    app/               # Исходный код сервера
packages/
  shared/
    contracts/         # Общие схемы запросов и ответов
docs/                  # Контекст проекта и документация интеграции
.env.example           # Пример серверных настроек
AGENTS.md              # Правила разработки
```

## Текущий статус

Мобильное приложение содержит таб-бар из Figma с пятью вкладками:
«Поиск», «Страны», «Мои eSIM», «Копилка», «Профиль». Во вкладке «Страны»
реализованы заголовок «Все направления», поле поиска, три переключателя,
карточка глобальной eSIM с переходом к тарифам, алфавитный список стран с боковым указателем букв
и карточки категорий на переключателе «Регионы». Данные загружаются через наш FastAPI.
В профиле подключён вход по коду из письма; на вкладке «Копилка» доступен тот же вход.
Начисления и баланс копилки ещё не подключены.
Подробнее: [мобильное приложение](apps/mobile/README.md).

Бэкенд на Python + FastAPI получает страны и категории через SDK поставщика
(`GET /v1/sdk/esims`), автоматически выпускает и обновляет ClientToken для каталога.
Из списка стран открывается экран тарифов по Figma: сроки, пакеты и цены
загружаются через `GET /v1/sdk/esims/{id}/tariffs`. Подключено оформление через
персональные SDK-заказы: расчёт, переход в кассу, проверка состояния и данные
установки в «Мои eSIM». [Сценарий, настройки и ограничения](docs/checkout.md).
Реальная оплата ещё не проверялась. Для локальной авторизации и защиты повторов используется SQLite;
база для развёртывания пока не выбрана. Подробнее: [экран тарифов](docs/tariffs-api.md).
Карточки категорий открывают [экран региона](docs/regions-api.md) со списком
стран и тарифами региональной eSIM при её наличии.

## Запуск приложения

Из корня репозитория:

```bash
npm ci --prefix apps/mobile
npm run dev
```

Откройте Expo Go на телефоне и отсканируйте QR-код. Телефон и компьютер
должны находиться в одной сети. Для браузерного просмотра: `npm run web`.
Проверка TypeScript: `npm run typecheck`.

Для загрузки каталога запустите бэкенд во втором терминале:

```bash
npm run api
```

Установка Python-зависимостей и настройка токена описаны в
[README сервера](apps/api/README.md). Сервер использует порт 8000;
клиент в браузере автоматически обращается к тому же hostname на этом порту.
Expo Go использует hostname сервера Expo. Для другого API можно задать
`EXPO_PUBLIC_API_URL` в `apps/mobile/.env`.

## Настройки

Для локальной настройки создайте `.env` из `.env.example`, если файл ещё не
создан, и заполните значения. Корневой `.env` автоматически загружается сервером. Не добавляйте
секреты в Git. Партнёрский токен поставщика должен использоваться только сервером.
Для SDK-каталога нужны обе настройки: `ESIM_PARTNER_TOKEN` и
`ESIM_PUBLISHABLE_KEY`. Подробности: [SDK-интеграция](docs/sdk-integration.md).

## Вход по почте

Профиль → «Войти по почте» → шестизначный код. SMTP-настройки задаются
только в корневом серверном .env. Аккаунты и сессии сохраняются локально,
на телефоне refresh-токен хранится в Expo SecureStore, в браузере — в HttpOnly cookie.
Настройка, Windows-команды и проверки: [email-auth.md](docs/email-auth.md).

## Разработка

Функции реализуются целиком: клиентский интерфейс, серверный API, необходимые
изменения данных и проверка пользовательского сценария. Общие контракты
клиента и сервера хранятся в `packages/shared/contracts`.

Перед реализацией ознакомьтесь с [контекстом проекта](docs/project-context.md)
и [сопоставлением экранов и API](docs/figma-api-mapping.md).
