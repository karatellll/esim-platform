# Правила работы с проектом

- Реализуй функции целиком: интерфейс, серверный API, логику бэкенда и
  необходимые изменения базы данных. Проверяй пользовательский сценарий
  от действия в приложении до получения и сохранения данных.
- Клиентское приложение размещай в `apps/mobile`, сервер — в `apps/api`,
  общие схемы API — в `packages/shared/contracts`.
- Бэкенд: Python + FastAPI. Мобильный клиент: React Native + TypeScript,
  запуск через Expo, навигация через React Navigation. Выбор базы данных
  пока не подтверждён.
- Подключай клиент к реальному API, когда контракт доступен. Если нужны
  демонстрационные данные, явно обозначай их и не выдавай интеграцию за готовую.
- Храни секреты и партнёрский токен только на сервере. В репозиторий добавляй
  примеры переменных окружения без действующих ключей.
- Перед работой с поставщиком прочитай `docs/project-context.md` и
  `docs/figma-api-mapping.md`. Не считай непроверенные маршруты и модели
  подтверждёнными; обновляй документацию по результатам проверки.
- При изменении API согласованно обновляй сервер, клиент и общий контракт.
- Документируй реальные команды запуска и необходимые настройки после
  создания приложений. Сообщай, какие проверки выполнены и что ещё не готово.
